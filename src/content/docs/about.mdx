# 1. Mission and scope

This project aims to document speedrunning strategies for the OG PS1 CTR. From track's routes, to shortcuts' cues, I try to include as much usefull information as possible.

The end goal would be to enable beginners like me to enjoy speedrunning this game without struggling too much to find the best techs and strats for their skill level.

# 2. Who is this for

This documentation is mainly oriented for beginners/intermediate runners. More experienced players might not find anything of interest, but their contribution will be the most welcomed.

# 3. How to use the documentation

Each track has it's own dedicated page. One should find a general overview of the track, and separated view for more specific information, such as routes & shortcuts, laps times to aim for and tips/notes to improve.

# 4. Contributions and corrections

I will try to open this on Github, so that everyone could contribute to the project.

# 5. Project background and acknowledgements

The project started around two weeks into my CTR speedrun journey. I used to play this game when I was very young and loved it. Thanks to a [great video on YouTube](https://youtu.be/M_5NESKqsVQ), I started to rerun this game in a less casual perspective.

During my speedruns, I noticed a lack of centralized tips and cues, despite having a very active and lovely speedrunning community. Having a scientific & IT background, I am more used to centralized and community-known documentation, I thought this game deserved one.
